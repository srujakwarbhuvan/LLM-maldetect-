┌──────────────────────────────────────────────────────────────┐
│ STEP 1: AUTOMATIC SETUP (Run Once)                          │
└──────────────────────────────────────────────────────────────┘

  Open PowerShell in d:\feature and run:
  
  → .\setup.bat
  
  This will:
  ✓ Create virtual environment
  ✓ Install all dependencies
  ✓ Configure the system


┌──────────────────────────────────────────────────────────────┐
│ STEP 2: ACTIVATE ENVIRONMENT (Every time you use it)        │
└──────────────────────────────────────────────────────────────┘

  → venv\Scripts\activate
  
  You'll see (venv) in your prompt when activated


┌──────────────────────────────────────────────────────────────┐
│ STEP 3: VERIFY IT WORKS                                     │
└──────────────────────────────────────────────────────────────┘

  → python verify_installation.py
  
  Should see: "🎉 All tests passed!"


┌──────────────────────────────────────────────────────────────┐
│ STEP 4: GET SOME APK FILES                                  │
└──────────────────────────────────────────────────────────────┘

  Place APK files in: d:\feature\data\input\
  
  Download from:
  • APKMirror.com (safe, trusted)
  • F-Droid.org (open source)
  • Your Android phone (backup apps)


┌──────────────────────────────────────────────────────────────┐
│ STEP 5: EXTRACT FEATURES! 🚀                                │
└──────────────────────────────────────────────────────────────┘

  SINGLE APK:
  → apk-extract single data\input\your-app.apk -o features.json
  
  MULTIPLE APKs:
  → apk-extract batch data\input\ -o data\output\features.csv
  
  VIEW RESULTS:
  → type data\output\features.csv

╔══════════════════════════════════════════════════════════════╗
║ TROUBLESHOOTING                                             ║
╚══════════════════════════════════════════════════════════════╝

Problem: "apk-extract not found"
Fix:     pip install -e .

Problem: "No APKs found"
Fix:     Place .apk files in data\input\

Problem: Setup fails
Fix:     Install Python 3.10+ from python.org

Problem: Execution policy error
Fix:     Run: Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
